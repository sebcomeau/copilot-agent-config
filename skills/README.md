# Skills

Custom skills contain reusable workflow instructions and supporting resources.

## Available Skills

- [`user-story-decomposition/`](user-story-decomposition/): evidence-based story planning and controlled Azure DevOps publication.

## Ownership

- `SKILL.md` owns planning gates, task structure, metadata, approval, and handoff.
- `PUBLISHING.md` owns publication transport, preflight, mutation, recovery, and read-back.
- `references/` contains machine-readable or supporting contracts.
- `scripts/` contains deterministic helpers and focused tests.
- `evals/` contains reusable behavioral evaluation scenarios.

Generated evaluation workspaces are ignored and belong outside source control.
